# Canadian SME Knowledge Base

Talkerstein's evidence-based reference on what Canadian small and medium-sized business owners, especially in Toronto and Ontario, need, ask and struggle with. It's the primary reference for the Canadian Business Terminal on the home page (Gemini API) and for future articles and guides.

The brief this follows is in [../RESEARCH-BRIEF.md](../RESEARCH-BRIEF.md).

## Status (2026-11-12)

All four pillars, the overview, industry research, regulations and the software directory are written. Every file cites the pages it relies on, and all 187 cited sources are in the [source register](09-sources/source-register.md). Anything that could not be checked against its source is labelled **Unverified**, **Estimate** or **Opinion** in place.

**Known gaps** (labelled in the files):

- **Search volumes:** no keyword tool data was available, so search volumes are not measured (see `07-keyword-research/`).
- **Regulator rules not read first-hand:** CPSO, RCDSO, OAA, PEO, Law Society of Ontario, AGCO advertising guidelines and IPC Ontario (PHIPA) pages blocked automated access. Those sections rely on secondary sources.
- **Missing prices:** Moneris, Microsoft 365 in CAD, ChatGPT, and Zoho and Make paid plans.
- **No Toronto-specific unemployment figure** for 2026 was found.
- **Time-sensitive items to re-check before relying on them:** Bill C-36 (federal privacy), Ontario Bill 194, the Canada Digital Adoption Program (closed), BDC LIFT, and all prices (read 2026-11-12).
- **Publication dates:** the 53 sources from the first pass have no publication dates recorded yet.

## Writing rules that matter to the terminal

The backend (`lib/terminal/knowledge.ts`) reads every `.md` file in this folder except this README.

- **Every document starts with the YAML frontmatter** from the brief. It's stripped before the text reaches the model.
- **One `#` title per file, then `##` / `###` sections.** Each section becomes one retrievable passage, so keep a section about one thing and name it descriptively. Sections over about 3,500 characters are split on paragraphs.
- **Cite inline with Markdown links**, as in `[GST/HST for businesses](https://www.canada.ca/…)`, right next to the claim. The terminal can only cite `https` URLs that appear in this folder.
- **Add every source to `09-sources/source-register.md`** using its table columns. The terminal reads a source's title and publisher from the register, so a source listed there shows its proper name on the page.
- **Label what kind of statement it is:** verified fact (with source), estimate, opinion, or recommendation. Never invent search volumes, prices or statistics.
- **Give dates** for anything time-sensitive, such as rates, thresholds, deadlines and program availability.
